
Methods
To identify robust behavioral dimensions and test their predictive power across varying experimental conditions, a multi-stage analysis was conducted. The pipeline involved data preprocessing, a robust Principal Component Analysis (PCA) to derive unbiased behavioral components, and a series of permutation-based hypothesis tests to assess the stability and context-dependency of the findings.
1. Data Preprocessing and Residualization
All behavioral features related to state frequency (freq50_s*), self-transitions (transsummary_self_trans_s*), and entropy (transsummary_row_entropy_s*) were identified as core features. To isolate the variance attributable to individual behavior from that of experimental conditions, these core features were first residualized. A linear model (lm) was fit for each feature to regress out the confounding effects of study_cohort and env_context. The resulting residuals, representing individual-level variation, were used for all subsequent analyses.
2. Robust Principal Component Analysis via Stratified Iterative Downsampling
To prevent the PCA from being biased by the imbalanced sample sizes across experimental contexts (e.g., the large N of the OFT context), a robust PCA method was employed. This involved an iterative procedure (N=5000 iterations) to generate a stable and unbiased set of PC loadings:
1.	Stratified Sampling: In each iteration, a balanced subsample was created by performing a stratified random sample, selecting exactly one observation from each unique (env_context, study_cohort) combination. This ensured every cohort's contribution to every context it participated in was weighted equally.
2.	PCA and Alignment: A standard PCA (prcomp) was performed on the balanced subsample. To ensure consistency across iterations, the resulting principal components were aligned by sign to a reference PCA (run once on the full dataset).
3.	Averaging: The 5000 aligned loading matrices were averaged to produce a single, highly stable, and unbiased set of loadings.
3. PC Score Calculation and Characterization
The final, unbiased PC scores were calculated by projecting the full, centered-and-scaled residualized data matrix onto the stable, unbiased loadings. The variance explained by these new PCs was quantified. To interpret the biological meaning of these components, their composition was visualized through variance decomposition plots, quantifying the contribution of each behavioral state ('node') and feature type ('characteristic') to the variance of the first four PCs.
4. Statistical Modeling and Robustness Testing
The predictive power of the first two unbiased PCs (PC1, PC2) on the label_binary outcome was tested using generalized linear mixed-effects models (glmer) with study_cohort included as a random intercept ((1 | study_cohort)). The significance and robustness of these relationships were assessed through two nested permutation analyses.
•	Test 1: Leave-One-Context-Out (LOCO) Permutation Test: To assess the generalizability of the PC effects, a LOCO analysis was performed. This involved iteratively excluding each of the four primary context groups (OFT, OFT_DUO, Y maze, and the combined Food_AST group) and running a permutation test on the remaining data. For each iteration, significance was determined by permuting the label_binary outcome 99 times within each study_cohort to generate a null distribution of z-scores. An empirical p-value was calculated by comparing the observed z-score to this null distribution. A finding was considered robust if it remained significant across all four LOCO scenarios.
•	Test 2: Paired-Context ("OFT Necessity") Permutation Test: Following the results of the LOCO analysis, a second analysis was conducted to formally test the hypothesis that the OFT context was a necessary component of a predictive model. Six models were constructed representing all possible pairs of the four contexts. The same grouped permutation test was applied to each of these six models to determine if PC2's predictive power was present only in pairs containing the OFT.
